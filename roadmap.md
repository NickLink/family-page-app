# План розвитку (Roadmap)

Цей документ окреслює потенційні напрямки для майбутнього розвитку та вдосконалення застосунку.

## 🎯 Короткострокові цілі (Найближчі 1-3 місяці)

- **Візуалізація вправ**:
  - Додати анімовані GIF-зображення або короткі відео для кожної вправи, щоб користувачі могли краще зрозуміти правильну техніку виконання.

- **Налаштування звуку**:
  - Додати елементи керування фоновою музикою: кнопка ввімкнення/вимкнення та регулятор гучності.
  - Надати можливість вибору з декількох фонових мелодій.

- **Пауза під час тренування**:
  - Реалізувати функцію паузи, щоб користувач міг тимчасово зупинити тренування та відновити його з того ж місця.

- **Покращення доступності (Accessibility)**:
  - Додати ARIA-атрибути для кращої взаємодії з екранними дикторами.
  - Перевірити та забезпечити повну навігацію за допомогою клавіатури.

## 中期️ Середньострокові цілі (3-6 місяців)

- **Кастомізація тренувань**:
  - Дозволити користувачам налаштовувати тривалість вправ та час відпочинку між ними.
  - Створити можливість формувати власні плани тренувань, обираючи вправи з доступного списку.

- **Історія та відстеження прогресу**:
  - Зберігати історію завершених тренувань у `localStorage` браузера.
  - Візуалізувати прогрес за допомогою простого календаря або графіків, щоб мотивувати користувачів.

- **Progressive Web App (PWA)**:
  - Додати Service Worker та Web App Manifest, щоб застосунок можна було "встановити" на головний екран пристрою та використовувати його офлайн.

- **Локалізація**:
  - Підготувати застосунок до перекладу на інші мови, винісши всі текстові рядки в окремі файли локалізації.

## 🌟 Довгострокові цілі (6+ місяців)

- **Профілі користувачів**:
  - Впровадити систему реєстрації (опціональну), щоб користувачі могли зберігати свій прогрес та налаштування в хмарі та синхронізувати їх між пристроями.

- **Нові програми тренувань**:
  - Розробити та додати нові комплекси вправ, наприклад, "Ранкова зарядка", "Тренування для постави", "Розтяжка для офісних працівників".

- **Гейміфікація**:
  - Ввести систему досягнень (ачівок) за регулярні тренування або виконання певних завдань для підвищення мотивації.

- **Інтеграція з API**:
  - Розглянути можливість інтеграції з фітнес-трекерами або API для здоров'я (наприклад, Google Fit, Apple Health) для більш глибокого аналізу активності.
