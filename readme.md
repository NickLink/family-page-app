# Тренування для стабілізації шиї

Цей веб-застосунок є персональним помічником для виконання 20-хвилинного комплексу вправ, спрямованого на зміцнення глибоких м'язів-стабілізаторів шиї, покращення постави та свідомий контроль над рухами. Програма розроблена спеціально для допомоги у протидії нервовим тікам через контрольовані та повільні навантаження.

## 🚀 Основні функції

- **Голосовий асистент**: Українськомовний асистент, який мотивує на початку, оголошує назву кожної вправи, контролює тривалість її виконання та хвалить після завершення тренування.
- **Структурований план**: 20-хвилинне тренування, розділене на 4 логічні фази: розминка, глибока стабілізація, зміцнення спини та розтяжка.
- **Фонова музика**: Легка та спокійна музика, що допомагає зосередитись та створює приємну атмосферу під час тренування.
- **Візуальний супровід**: Інтуїтивно зрозумілий інтерфейс з таймером, що показує час до кінця вправи, та індикатором загального прогресу тренування.
- **Адаптивний дизайн**: Застосунок коректно відображається на настільних комп'ютерах, планшетах та мобільних пристроях.

## 📋 Як користуватися

1.  **Відкрийте застосунок**: Зайдіть на сторінку у вашому браузері.
2.  **Ознайомтесь з інформацією**: На стартовому екрані ви побачите мету та ключові рекомендації до тренування.
3.  **Натисніть "Старт"**: Щоб розпочати тренування, натисніть велику кнопку "Старт".
4.  **Слухайте та виконуйте**: Голосовий асистент промовить мотиваційну фразу, після чого оголосить першу вправу. Таймер на екрані почне відлік.
5.  **Слідуйте інструкціям**: Виконуйте вправи згідно з описом на екрані та голосовими підказками. Програма автоматично перемикатиме вас між вправами.
6.  **Завершення**: Після виконання останньої вправи асистент повідомить про завершення, і на екрані з'явиться можливість розпочати тренування знову.
