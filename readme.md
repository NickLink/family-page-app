# Затишний сімейний закуток

"Затишний сімейний закуток" — це персональний веб-застосунок, створений як централізований хаб для різноманітних сімейних активностей, планів та інформаційних ресурсів. Він поєднує в собі інструменти для підтримки здоров'я та спорту з ідеями для відпочинку та розваг, надаючи зручний та інтерактивний досвід для всіх членів родини.

## 🚀 Основні функції

Застосунок має чітку модульну структуру, розділену на два основні напрямки:

### 1. Розділ "Спорт і здоров'я"

Цей розділ є комплексною базою знань та інструментів для підтримки фізичного та ментального здоров'я.

- **Інтерактивне тренування для шиї**:
  - 20-хвилинний комплекс вправ для стабілізації шиї.
  - Покроковий супровід з таймером для кожної вправи.
  - **Голосовий асистент** (Web Speech API) українською мовою, який оголошує вправи та надає мотивацію.
  - Фонова музика для створення приємної атмосфери.

- **План тренувань Костянтина**:
  - Інтерактивна 3-денна програма тренувань ("Push", "Pull", "Full Body").
  - **Двомовна підтримка** (українська та англійська).
  - Детальний опис кожної вправи з посиланнями на відео-приклади.
  - **Візуалізація даних** (Chart.js) у вигляді діаграм, що показують обсяг навантаження на різні групи м'язів для кожного тренувального дня.

- **База знань про здоров'я**:
  - **HRT (Тренування зі зміни звички)**: Детальний посібник з поведінкової терапії для контролю нервових тіків.
  - **План прийому вітамінів**: Структурована інформація про рекомендовані добавки та їхню дію.
  - **План контролю режиму дня**: Покроковий план для поступової нормалізації сну та покращення його якості.

### 2. Розділ "Відпочинок і розваги"

Цей розділ призначений для спільних хобі та розваг.

- **Кодекс Коктейлів**:
  - Інформаційна сторінка, що базується на теорії "6 кореневих коктейлів".
  - Включає рецепти, концепції та варіації для таких класичних напоїв, як Old Fashioned, Martini, Daiquiri та інших.
  - Містить посилання на відео-джерело для наочності.

## 🛠️ Технологічний стек

- **Framework**: [React](https://reactjs.org/) (v19) для побудови компонентного інтерфейсу.
- **Мова**: TypeScript для типізації та підвищення надійності коду.
- **Стилізація**: [Tailwind CSS](https://tailwindcss.com/) для швидкого створення сучасного дизайну (підключається через CDN).
- **Візуалізація даних**: [Chart.js](https://www.chartjs.org/) для створення інтерактивних діаграм у плані тренувань Костянтина.
- **Голосовий супровід**: [Web Speech API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Speech_API) для реалізації функцій голосового асистента.

## 📂 Структура проєкту

Проєкт має чітку компонентну архітектуру, де кожен екран або функціональний блок винесено в окремий компонент.

- `App.tsx`: Головний компонент, що керує навігацією (маршрутизацією) між різними екранами застосунку.
- `components/`: Директорія, що містить усі UI-компоненти.
  - `LandingScreen.tsx`: Головний екран-хаб.
  - `HealthScreen.tsx` / `LeisureScreen.tsx`: Екрани-меню для відповідних розділів.
  - `HrtScreen.tsx`, `PillsScreen.tsx`, `RoutineScreen.tsx`, `CocktailsScreen.tsx`: Інформаційні сторінки.
  - `WorkoutApp.tsx`: Компонент, що містить логіку інтерактивного тренування для шиї.
  - `KostyaScreen.tsx`: Компонент, що реалізує інтерактивний план тренувань Костянтина.
- `hooks/`: Директорія з кастомними хуками (наприклад, `useSpeechSynthesis.ts`).
- `constants.ts` / `types.ts`: Файли для зберігання статичних даних (плани тренувань) та типів TypeScript.
