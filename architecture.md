# Архітектура застосунку

Цей документ описує технічну архітектуру веб-застосунку "Тренування для стабілізації шиї".

## Frontend Стек

- **Framework**: [React](https://reactjs.org/) (v19) для створення декларативного та компонентного інтерфейсу користувача.
- **Мова**: TypeScript для типізації та підвищення надійності коду.
- **Стилізація**: [Tailwind CSS](https://tailwindcss.com/) для швидкого створення сучасного дизайну за допомогою utility-first підходу. CSS-фреймворк підключається через CDN.
- **Середовище виконання**: Застосунок є повністю клієнтським (client-side) і не потребує серверної частини. Усі операції виконуються у браузері користувача.

## Керування станом

Керування станом реалізовано за допомогою вбудованих хуків React:
- `useState`: для керування локальним станом компонентів (наприклад, поточний стан тренування `workoutState`, час `timeLeft`).
- `useRef`: для отримання доступу до DOM-елементів (наприклад, до аудіо-плеєра `<audio>`).
- `useCallback`: для мемоізації функцій та уникнення зайвих ре-рендерів.
- `useEffect`: для керування побічними ефектами, такими як запуск таймерів та взаємодія з Web Speech API.

## Структура компонентів

Застосунок має чітку компонентну структуру:

- `App.tsx`: Головний компонент, що виступає в ролі контейнера. Він керує загальним станом програми (`idle`, `running`, `finished`), перемикає екрани та керує фоновою музикою.
- `components/StartScreen.tsx`: Початковий екран, що містить опис тренування та кнопку для його запуску.
- `components/WorkoutView.tsx`: Основний екран тренування. Відображає назву поточної вправи, опис, таймер та загальний прогрес. Відповідає за голосовий супровід кожної вправи.
- `components/CompletionScreen.tsx`: Екран, що з'являється після успішного завершення тренування.
- `components/CircularProgress.tsx`: Перевикористовуваний UI-компонент, який візуалізує таймер у вигляді круглого індикатора прогресу.

## Кастомні хуки

- `hooks/useSpeechSynthesis.ts`: Ізольована логіка для роботи з браузерним **Web Speech API**. Цей хук надає просту функцію `speak(text, onEndCallback)` для озвучування тексту та виконання дії після завершення мовлення.

## Дані та типи

- `constants.ts`: Містить статичний масив `WORKOUT_PLAN` з усіма вправами, їхнім описом, тривалістю та іншими параметрами. Це дозволяє легко змінювати або розширювати програму тренувань.
- `types.ts`: Визначає TypeScript-інтерфейс `Exercise` для забезпечення типізації даних про вправи в усьому застосунку.

## Загальна структура файлів

```
/
├── index.html                # Головний HTML-файл
├── index.tsx                 # Точка входу в React-застосунок
├── App.tsx                   # Кореневий компонент
├── constants.ts              # Дані тренування
├── types.ts                  # TypeScript типи
├── components/               # Директорія з UI-компонентами
│   ├── StartScreen.tsx
│   ├── WorkoutView.tsx
│   ├── CompletionScreen.tsx
│   └── CircularProgress.tsx
└── hooks/                    # Директорія з кастомними хуками
    └── useSpeechSynthesis.ts
```
